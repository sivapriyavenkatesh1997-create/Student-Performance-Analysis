# Student Performance Analysis using Python

## Project Overview

This project focuses on analysing student academic performance using Python, NumPy, Pandas, and Matplotlib.

The objective is to evaluate student marks, attendance, subject-wise performance, pass/fail status, and department-wise academic performance. Data analysis and visualization techniques are used to identify performance trends and students who may require additional academic support.

## Dataset Description

The dataset contains information about 10 students across five subjects.

**Student Details:**
- Student ID
- Student Name
- Attendance Percentage
- Department

**Academic Subjects:**
- Python
- SQL
- Pandas
- Excel
- Power BI

**Pass Criteria:** Students must score at least 35 marks in each subject to pass.

## Technologies Used

- Python – Programming and data analysis
- NumPy – Numerical calculations and statistical analysis
- Pandas – Data manipulation and DataFrame operations
- Matplotlib – Data visualization

## Project Tasks and Analysis

### 1. Python Fundamentals
- Created student lists and subject-wise marks.
- Calculated total and average marks using loops.
- Identified Pass and Fail students using conditional statements.

### 2. NumPy Analysis
- Created NumPy arrays for student marks.
- Calculated total and average marks.
- Identified maximum and minimum marks in each subject.
- Calculated median and standard deviation.
- Identified students with average marks below 50.

### 3. Pandas Analysis
- Created a DataFrame containing student details and marks.
- Calculated total and average marks.
- Identified students with low attendance.
- Identified the student with the highest total marks.
- Calculated department-wise average marks using groupby().
- Identified subjects with the highest and lowest average marks.
- Sorted students based on average marks.
- Analysed student performance based on attendance and marks.

### 4. Data Visualization using Matplotlib

Created the following visualizations:

1. **Bar Chart:** Average marks of each student.
2. **Histogram:** Distribution of marks across subjects.
3. **Pie Chart:** Total marks distribution among students.
4. **Line Chart:** Average marks comparison across subjects.
5. **Scatter Plot:** Relationship between attendance and average marks.
6. **Grouped Bar Chart:** Comparison of passed and failed students by subject.

## Key Findings

- Analysed the academic performance of 10 students across five subjects.
- All 10 students passed all five subjects based on the 35-mark pass criteria.
- Identified the highest and lowest performing students.
- Evaluated subject-wise average marks.
- Analysed attendance percentages to identify students who may need academic support.
- Compared department-wise average academic performance.
